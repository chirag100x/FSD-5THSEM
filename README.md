# My FSD Learning Journey in College

This repository captures my Full Stack Development (FSD) practice journey during college. It includes hands-on exercises, mini tasks, and concept-based files that helped me move from JavaScript basics to building simple interactive shopping experiences.

## About This Journey

I created this project as part of my semester learning to strengthen my understanding of web development fundamentals. Instead of only reading theory, I practiced by building small features and experimenting with code structure, browser APIs, and user interaction.

## What I Learned

### 1. JavaScript Fundamentals
- Variables, functions, and scope
- Closures and function behavior
- Working with arrays and object data
- Writing reusable logic in separate files

Practice files:
- function.js
- scope.js
- script.js
- index.js

### 2. Promises and Async Concepts
- Understanding asynchronous JavaScript
- Using Promises and promise chaining
- Fetching remote data from APIs
- Handling success and error states

Practice files:
- promise.html
- day3/promise.js
- day4/fetch.js

## Skills Gained
- Better confidence in JavaScript problem solving
- Understanding of how frontend pages communicate through shared browser state
- Ability to build small feature flows from scratch
- Debugging and improving existing code through iteration

## Challenges I Faced
- Handling dynamic data cleanly in the DOM
- Keeping UI state and stored state in sync
- Avoiding bugs caused by single-item storage patterns

## How This Repo Helps Me
This repository works as my personal revision notebook. Each file reminds me of a concept I learned and how I implemented it in practice. It also helps me track my progress semester by semester.
